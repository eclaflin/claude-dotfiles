# claude-dotfiles

This repo contains my personal Claude Code skills and commands, symlinked into ~/.claude/.

## Structure
- `skills/` — Custom skills, loaded by Claude Code automatically
- `commands/` — Custom slash commands

## Conventions
- Each skill lives in its own folder with a SKILL.md
- Skill origins are documented in CREDITS.md
- Don't modify CREDITS.md without updating the appropriate section

## When adding a new skill
1. Create a folder under skills/
2. Add a SKILL.md following the standard frontmatter format
3. Update CREDITS.md with origin and attribution
